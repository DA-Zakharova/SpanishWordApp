# Spanish Word of the Day 🇪🇸

A small React application that generates a random Spanish word and translates it into Russian.  
The project was built to practice working with React hooks, async API requests, and basic UI interactions.

---

## ✨ Features

- Generates a random Spanish word on page load
- Fetches new words on button click
- Translates the word into Russian
- Shows loading state while fetching data
- Uses free public APIs
- Simple and clean responsive UI

---

## 🧠 What I practiced

- React Hooks (`useState`, `useEffect`)
- Async / Await with Fetch API
- Conditional rendering
- Handling loading states
- Working with external APIs

---

## 🔗 APIs Used

- Random Spanish Word API:  
  https://random-word-api.herokuapp.com/word?lang=es

- Translation API:  
  https://api.mymemory.translated.net/get
